# SPECTER Support

Use the issue form in this repository to report a reproducible problem with the SPECTER Stremio add-on. Include the app and device version, what you tried, what happened, and a redacted error or safe diagnostics when available.

**Reports are public. Never include provider API keys, passwords, tokens, private install or manifest URLs, or personal information.**

SPECTER is an independent project. This repository is only for support reports; it does not contain the add-on source code.
